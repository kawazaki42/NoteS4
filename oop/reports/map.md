Ассоциативный массив (словарь) - абстрактная структура данных, хранящая пары ключ-значение

В Kotlin они представлены интерфейсами `Map` и `MutableMap`,
и обычно

Конкретная реализация обычно не упоминается, но
для хранения порядка вставки элементов используется
`LinkedHashMap`.

Чтобы создать экземпляр (реализации) интерфейса `Map` используется функция `mapOf`.

Она принимает список пар _ключ-значение_ в виде списка аргументов.

```kotlin
val jvmLangs = mapOf(
    "Java" to "C",
    "Groovy" to "Ruby",
    "Kotlin" to "Swift",
)
```

Ключом может выступать любой тип. Сравнение ключей зависит от реализации,
но в общем случае через `operator fun Any.equals` (`==`)

Интерфейсу `MutableMap` соответствует функция `mutableMapOf`.

Также существует функция `buildMap`.
Она создает словарь при помощи лямбды в контексте временного
`MutableMap`, и возвращает `Map` (неизменяемый).

```kotlin
val squares = buildMap {
    for (i in 0..9) {
        put(i, i*i)
        if (i == 5) break;
    }
}
```

В отличие от Java, в Kotlin есть перегрузка операторов,
поэтому доступ к элементам возможен при помощи оператора `[]`:

```kotlin
val langs = mutableMapOf()

langs["jvm"] = "Java"

println(langs["jvm"])

langs["jvm"] = "Kotlin"
```

оператор `[]` (`operator fun get`) возвращает значение типа `T?` --
оно равно `null` если такого ключа нет в словаре.
