Regex
- метасимволы
  - `.` - любой символ
  - `\d` - любая цифра
  - `\D` - любая НЕ цифра
  - `[]` - символ из множества
- _квантификаторы_
  - `*` - 0+ повтрений
  - `+` - 1+ повтрений
  - `?` - 0-1 символ
  - `{n}` - ровно n повторений
  - `{n,m}`: n-m повторений (включительно)

```
/[А-ЯЁ][а-яё]*\s+[А-ЯЁ][а-яё]*/
/[А-ЯЁ][а-яё]{2,}/
```

- `^` - началало строки
- `$` - конец

- `^.+$` - ищет каждую строку ненулевой длины
- `\b` - граница слова

- `(смарт|теле)фон`
