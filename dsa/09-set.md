multiset (_мультимножество_)

реализация через массив

- добавление: в конец массива, но только если уже нет такого O(n)
- удаление: зависит от положения элемента, O(n), даже n + n
- проверить наличие: O(n)
- inplace union: $O(m * n)$
- inplace substract: O(m * n)
- inplace intersect: O(m * n)
- inplace sym. diff: O(m * n)

битовые множества

вспоминаем битовые операции

```c
1 & 0 == 0;  // 001 & 000 = 000
1 & 3 == 1;  // 001 & 011 = 001
2 & 5 == 0;  // 010 & 101 = 000
```

```pseudo
0b001 >> 1 => 0b000

1 => 0
2 => 1
4 => 2

0b010 >> 1 => 0b001

0b100 >> 1 => 0b010

0b001 << 1 => 0b010

1 => 2
```
