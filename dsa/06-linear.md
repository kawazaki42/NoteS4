  - в конец O(1)
- удаление

  - конца O(1)

- `rear` - индекс O(1)

# блочный массив

связный список из массивов

# связный список

```
[4|*]->[15|*]->[7|*]->[40|*]->NULL
^ Head
```

элементы (узлы)

- односвязный
  - развернутый
- двусвязный
- кольцевой

## операции

- доступ (по индексу) O(n)
- вставка
  - в начало O(1)
  - в середину O(n)
  - в конец O(n) [^1]
- удаление
  - в начало O(1)
  - в середину O(n)
  - в конец O(n) [^1]

## реализация

- значение
- указатель на следующий узел

для работы со списком необходимо знать указатель на 1ый узел: `head`

[^1]: можно кэшировать последний элемент, тогда: O(1)
