Данные:
- указатель на кучу `int *arr = new int[capacity]`
- capacity - количество выделенной памяти
- size - число фактически хранимых элементов

притча про незабитие нулями...

Операции:
- изменение размера и емкости
  - резервирование памяти под `n` элеменов
- добавление элемента в конец
- добавление в начало
- добавление в `i`-позицию (произвольную) (`insert`)
- удаление из конца
- начала
- `i`-позиции
- получить размер (`size`)
  - узнать пуст ли массив
- получить емкость (`capacity`)
- доступ к элементу по индексу (`i`)
  - front (1-й элемент)
  - back (последний)
- пререзапись элемента по индексу
- очистка
- копирование
  - см. "правило пяти"

> Форд-Топп, структуры данных C++

Плюсы:
- простота использования и реализации
- доступ O(1)

Минусы:
- выделение памяти единым блоком
  - может не хватить памяти под копирование
  - фрагментация
- медленная вставка и удаление в середине
