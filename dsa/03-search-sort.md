# Последовательный поиск

- O(n)
  - средний и худший
- O(1)
  - лучший
- по памяти:
  - O(1)
  - только индекс или указатель
- не требует вызова `<` / `>`
- работает на неупорядоченных числах

# Бинарный поиск

- требует отсортированный массив
- тыкаемся в средний элемент (не арифметический, а по индексам!)
- `a[mid] == t => return mid`
- `a[mid] < t => /* ищем правее */ {l = mid+1; r = r;}`
- `else { /* ищем левее */ l = l; r = mid-1; }`

```c++
int target = 7;
size_t l = 0;
size_t r = 16;

// might overflow!
// mid = (l+r)/2;

size_t mid = l + (r-l)/2;  // 8

if (a[mid] == target) {  // 14 != 7
    
} else if (a[mid] < target) {  // 14 >= 7
    
} else {
    // a[mid] > 7
    // ищем слева
    l = l;
    r = mid-1;  // 7
}

// ---

l = 0;
r = 7;

mid = 3;

a[mid] == target  // 6 != 7
a[mid] < target   // 6 < 7 => ищем справа

l = mid+1;  // 4
r = r;      // = 7

// ---

l = 4;
r = 7;

mid = 5

a[mid] == target  // 8 != 7
a[mid] < target   // 8 >= 7
a[mid] > target   // 8 > 7 => ищем слева

l = l;      // 4
r = mid-1;  // 4

// ---

l = 4;
r = 4;

mid = 4

a[mid] == target  // true

return 4;
```

log_2 (n)

- worst: O(log_2 n)
- average: O(log_2 n)
- best: O(1)

- память:
  - O(1) - итеративный

# Интерполяционный поиск

(x - x_0) / (x_1 - x_0) = (y - y_0) / (y_1 - y_0)

(x - x_0) / (x_1 - x_0) * (y_1 - y_0) + y_0 = y

(a - a_0) / (a_1 - a_0) * (i_1 - i_0) + i_0 = i

```
t = 7;

a_0 = 1;
a_1 = 71;

ind_0 = 0;
ind_1 = 16;

ind = (7 - 1) / (71-1) * (16 - 0) + 0;

// ind = 0.086 * 16 = 1.37;
ind = 1;

a[ind] == t;  //
a[ind] < t;   //
```

такой поиск быстрее чем бинарный для данных которые равномерно возрастают

- worst:  $O(n)$
- avg:    $O(log[log(n)])$
- best:   $O(1)$
- Память: $O(1)$
