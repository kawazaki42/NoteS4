очередь на основе динамического массива:
- enqueue: в начало массива - O(n); в конец массива - O(1) амортизированно
- dequeue: из конца массива O(1); из начала массива - O(n)
- peek: получить элемент который "первый пришел": O(1)
- size: O(1)

связный список
- enqueue - O(1) с обеих сторон списка
- dequeue - O(1) с обеих сторон списка
- peek - O(1)*
- size - O(1)*

доп. память:
- связный список: начало + конец + размер + n * след. указатель O(n)
- дин. массив: начало + размер + вместимость; O(1)

кольцевой буфер (динамический):
- enqueue: O(1) амортизированно с обеих сторон буфера
- dequeue: O(1)
- peek: O(1)
- size: O(1)

Radix Sort - поразрядная сортировка

унитарный код - aka one_hot

см. также: перфокарта

```kotlin
input.groupBy { it % 10 }.map(::Queue)
```

```kotlin
input.groupBy { i: Int -> i / 10 }.map(::Queue)
```

этот алгоритм даже не требует прямого сравнения чисел

Время: O(w * n)

w - кол-во разрядов

Память: O(w + n)

Deque

Priority Queue: сортированная очередь

на основе дин. сорт. массива:
- добавление (не в начало/конец, а по приоритету)
  - найти позицию: O(log n)
  - сдвинуть для вставки: O(n)
  - итого: O(n)
- удаление (всегда из начала очереди)
  - подробность реализации: удаление из конца
  - O(1)
- peek (next_preview): O(1)
- size: O(1)
- clear: O(1) (без учета деструкторов)
  - если есть деструкторы: O(n)
