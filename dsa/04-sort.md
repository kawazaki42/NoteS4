Свойства сортировок:
- Устойчивость
  - одинаковые элементы не меняются местами
- Естественность
  - что делать если он уже сортирован (возможно частично)
- Использование операции сравнения
  - может использовать не сами элементы, а разряды, например
- Сложность (O)

Оптимально: $O(n \cdot \log n)$

- Внутренние
  - произвольный доступ
- Внешние
  - для больших объемов
  - читая с диска

_Ключ_ - признак элемента массива для сортировки
- может быть несколько сразу, или по отдельности, в зависимости от задачи

_Сопутствующие данные_ - все остальное

```
class Weather {
  + city
  + H
  + T
}
```

# Пузырьковая

попарное сравниние и обмен переменными

один проход: n-1; O(n)

последний элемент гарантированно в конце

n-2; O(n)

у нас n-1 проходов (т.к. последний элемент двигать не надо)

итого сложность O(n^2)

средний тоже

лучший: O(n)

# Вставками

такая же сложность как у пузырьков

"паровозик" из сортированой части

т.е. берет элементы из неотсортированной (_правой_ части)
и ищет правильный индекс в отсортированной

# Выбором

основано на поиске минимального

во всех случаях O(n^2)

самая наивная

# Сортировка Шелла

есть моды

основан на вставках

сравнительно быстр если правильно настроить

параметр: расстояние (offset) d > 0

после прохода меняем d (уменьшаем)

1. $d_1 = N/2; d_i = d_(i-1)/2; d_k = 1$
   - худший случай: O(N^2)
   - средний: O(N^(3/2))
2. Эмпирические последовательности
  - Марцианна Циура
    - 1 4 10 23 57 132 301 701 1750
    - работает для N < 4000
  - Фибоначчи
  - Хиббарда
    - $d = 2^i - 1$

# Быстрая сортировка

"разделяй и властвуй"

1. _опорный_ элемент
2. делим элементы на те что меньше и больше него
3. рекурсируем на обоих частях

память O(1)

O(log n)

возьмем медиану из 3

рандом быстрее первого/последнего
