# по законам кирхгофа

Ветви:
1. ab (R1)
2. db (R2, E2)

5. dc (R5, E5)

по 1 закону: 4-1=3 уравнения

по 2 закону: 6-3=3 уравнения

> 1 закон: алгебраическая сумма токов в узле равна нулю

- a: -I1 -I4 -I6 = 0
- b: +I1 +I2 +I3 = 0
- c: -I3 +I5 +I6 = 0

- abda (R1, E2, R2, R4)
