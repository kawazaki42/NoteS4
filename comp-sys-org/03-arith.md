# Арифметические основы ЭВМ

Система счисления - система приемов наименования и записи чисел с помощью некоторого набора символов: __цифр__

числа состоят из нек-го набора символов (__цифр__)

макс. кол-во цифр называется __алфавитом__ системы счисления

Непозиционные системы
- римская
  - X
  - XX
  - XXX
  - XL
- египетская
- греческая
- недостатки:
  - сложно делать арифметику
- современное применени: в основном декоративное

Позиционные системы счисления: значение каждой (вес) цифры зависит от положения в числе (разряда)
- арабская
  - 1
  - 10
  - 100

Алфавит позиционной системы счисления ($s$) называется основанием системы счисления

Ну или макс. значение в разряде

Определяет макс. возможное кол-во чисел, записываемых в этой системе

$s$-ичная система счисления

Все позиционные системы счисления обладают аддитивно-мультипликативности.

Если по-русски, число можно представить в виде многочлена

```
x = e_r * s^r + e_{r-1} * s^{r-1} + ...
```

## Формы представления чисел


В общем случае помимо цифр числа, необходимо хранить:
- его знак
- положение точки/запятой (разделителя целой и дробной части)

под знак обычно выделяется старший разряд (__знаковый__):
- 0 -> +
- 1 -> -

для указания положения точки используются две формы записи чисел:
- фиксированная
  - предполагает что все числа либо чисто целые, либо чисто дробные
  - в этом случае положение точки стандартно и не требует указания
  - для целых: точка зафиксирована справа от младшего разряда (а потом нули разумеется)
  - для дробных: точка зафиксирована слева от старшего разряда (а перед ней все нули)
  - недостатки:
    - не позволяет хранить смешанные числа (целое + дробь)
  - часто используется как вспомогательная форма
- плавающая (`float`)
  - более универсальна
  - $A = m_A * s^P$
  - число состоит из 2 частей:
    - мантисса ($m_A$)
      - хранит цифры числа
      - записывается как дробное число с фикс. точкой
    - порядок ($P$)
      - положение точки
      - записывается как целое с фикс. точкой
      - знак задает направление смещения точки
        - "+" -> вправо
        - "-" -> влево
  - знак числа равен знаку мантиссы
    - его обычно выносят в общий знаковый разряд
  - пример:
    - A = -123.456
      - $m_A = -0.123456$
      - P = +3
    - A = 0.00123456
      - $m_A = 0.123456$
      - P = -2
  - может быть нормализованным и ненормализованным
    - не нормализовано: если 1ая цифра мантиссы после запятой равна нулю
    - нормализовано: есла не равна
      - позволяет хранить больше значащих цифр
        - поэтому перед записью в память числа нормализуются
      - как нормализовать: двигаем число влево с уменьшением порядка
  - для увеличения точности при хранении мантиссы двоичных чисел
    - используется __способ скрытой единицы__
      - старший бит числа не хранится, т.к. он всегда равен 1
      - `P -= 1`
      - в осовободившийся разряд можно дописать еще одну цифру
      - перед арифметическими операциями старший бит надо восстановить
  - смещенный порядок
    - бывает пол. и отр.
    - для упрощения операций его часто смещают
    - $P_s = P + 2^(q-1)-1$
      - степень двойки минус один называется смещением
    - $q$ - кол-во разрядов порядка
    - это чтобы вывести операции в положительные числа
    - чтобы найти обычный порядок надо вычесть смещение

### Распространенные форматы хранения чисел с плавающей точкой

- знак
- смещенный порядок
- модлуь мантиссы

#### binary32

- aka `float` in `C`
- 1 бит под знак
- 8 бит под порядок
- 23 бита под модуль мантиссы

#### binary64

- aka `double` in `C`
- 1 бит под знак
- 11 бит под порядок
- осуждаем бит под модуль мантиссы

### Пример

Записать 10чном виде числа с плавающей точкой
- в одинарном формате
- со смещенным порядком
- и скрытой единицей

1 10000010 1001000...

- старший бит 1 -> отрицательное число
- порядок (8 бит): 10000010 -> 130 -> 130 - 127 = 3 (вычитаем смещение)
- восстанавливаем 1цу: 1.1001
- применяем порядок (сдвиг на 3): 1100.1 -> -12.5

чтобы записать 0 -> смещенный порядок равен 0000 0000; мантисса не важна

бесконечность -> смещенный порядок = 1111 1111; мантисса желательно 0

бесконечности имеют знак!

# Машинные коды для представления чисел в ЭВМ

> Большинство машинных операций в компьютере сводится с сложению и сдвигу

Чтобы преобразовать операции к сложению,
используются _машинные коды_:
- Прямой
- Обратный
- Дополнительный

Положительные числа во всех кодах записываются одинаково

Для записи числа в прямом коде, к нему добавляется знаковый разряд.
- 1 -> -
- 0 -> +
- остальные разряды -> без изменения

Чтобы получить обратный код отрицательного числа,
необходимо проинвертировать числовые (цифровые) разряды
прямого кода

Чтобы получить дополнительный код отрицательного числа,
необходимо прибавить 1 к обратному коду (если число отрицательное!)

Для получения прямого кода отрицательного числа из дополнительного,
выполняется инверсия цифровых разрядов и прибавляется единица

_промежуточный_ код

в лабе тоже без вычитания делаем!

для Некоторых операций используются модифицированные коды

Они отличаются наличием двух знаковых разрядов

в _нормальном_ режиме:
- `+` -> 00
- `-` -> 11

это нужно для отслеживания переполнения: 01 или 10

## сложение

1. операнды выравниваются до одинакового кол-ва разрядов
2. у целого меншего по разрядности числа дописываются нули слева, у дробного - справа
3. операнды переводятся в дополнительный код
4. поразрядное сложение операндов начиная справа

> знаковый разряд также участвует в операции

> при сложении чисел в дополнительном коде перенос из знакового разряда отбрасывается

результат в дополнительном коде, тк. операнды в нём

его надо будет перевести в прямой код

- но это только для одноименных чисел

## умножение

кол-во шагов равно разрядности множителя

на каждом шаге умножаем на одны цифру множителя

получаем частичное произведение (ЧП)

резултат - сумма всех чп, сдвинутых

направление сдвига зависит от метода

результат в 2 раза длиннее множителей

знак вычисляется отдельно

> при перемножении двоичных чисел ЧП будут равны либо множимому либо нулю
>
> всё сводится к сложению и сдвигу

## деление

делимое в два раза больше (2n) делителя и частного (n)

для дробей - все имеют размер n

возможно переполнение - когда частное не помещается

не возникнет, если число в старшей половине делимого (в n разрядах) меньше делителя (для целых чисел)

или делимое меньше делителя (для дробных)

ъето надо проверить перед делением

### с восстановлением остатка

не рассмотрели

### без восстановления остатка

он короче

> все вычисления - в мод. доп. коде

> алгоритм не учитывает знаки; деление выполняется по модулю; знак вычисляется отдельно

- модуль делителя размещается в старших n разрядах двойного слова
- проверяется отсутствие переполнения
    - из делимого вычитается делитель
    - анализируется знак остатка (результата)
        - положительный -> деление невозможно (будет переполнение)
        - отрицателный -> деление продолжается
- (4) остаток сдвигается влево на 1 разряд; крайный левый бит отбрасывается, знаки участвуют в сдвиге
    - справа ноль
- проверяется знак остатка до сдвига
    - положительный -> из сдвинутого остатка вычитается делитель
    - иначе -> делитель прибавляется
- знак полученного остатка:
    - положительный -> v chastnoe idet 1ka
    - иначе -> 0
- условие окончания: частное в 2 раза больше делимого
    - иначе возвращаемся к пункту (4)
- последний остаток - общий остаток операции
    - если он отрицательный - восстанавливаем его, добавив делитель

## Операции над числами с плавающей точкой

Особенности сложения и вычитания:
- Разные порядки
  - Но выполнять операции с разрядами мантисс можно только при одинаковом весе
  - Перед операцией их надо выровнять
    - Сравниваются порядки
    - Мантисса с меньшим порядком сдвигается вправо на кол-во разрядов,
      - равное модулю разности порядков
      - При этом младшие разряды теряются
    - Порядок суммы равен большему из порядков операндов
    - Сдвиг происходит потактово
  - После выравнивание складываем мантиссы, как дробные числа с фикс. точкой
  - После сложения результат нормализуется
  - Операции выполняются в доп. коде

попробуем без скрытой единицы и смещенных порядков

### Умножение

M_A = 2^{P_A}

(M_A * M_B) * (2^{P_A + P_B})

- Мантисса произведения будет равна произведению мантисс сомножителей
  - Умножаются как фиксированная точка
- Порядок будет равен сумме порядков
  - Складываются как целые числа

### Деление

почти то же самое, но `/` и `-`

мантисса частного равна частному мантисс

порядок равен разности порядков делимого и делителя
