Электричество

$e^-$, $p^+$

Электричество возникает в специальных материалах - _проводниках_

интенсивность движения частиц определяется разностью потенциалов: $q_2 - q_1 = U$ - оно же _напряжение_

- q_2 +
- q_1 -

сопротивление: R - свойство проводника

I - кол-во частиц, проходящих через поперечное сечение проводника за единицу времени

I = U/R

Нам надо нарисовать + и - у источника ЭДС

```
+ V U E T /|\

- G GND _|_ =|=

o /o
```

## Резистор

```
R -[  ]- -/\/\/\-
```

Это проводник с заранее заданным известным сопротивлением

обеспечивает ограничение тока

делитель напряжения

## Диод

```
D
Анод +  - |> |-  Катод -
```

Может пропускать ток только в 1 направлении: от _анода_ к _катоду_

Диодно-резисторная логика

Принцип наименьшего сопротивления

т.н. стяжка - резистор к земле

Минус: она энергонеэффективна

Поэтому есть т.н. _транзисторная логика_

## Биполярные транзисторы

```
      | Коллектор
База--K
      | Эмиттер
```

pnp: 0 - открывается

нагрузка к эмиттеру
